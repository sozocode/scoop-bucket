# VisuaLeaf Scoop bucket

Install [VisuaLeaf](https://visualeaf.com) on Windows with [Scoop](https://scoop.sh):

```powershell
scoop bucket add visualeaf https://github.com/sozocode/scoop-bucket
scoop install visualeaf/visualeaf
```

Update with `scoop update visualeaf`. VisuaLeaf's own updater is turned off in Scoop installs, so
Scoop stays in charge of the files.
